# DSA Beginner 1

A beginner-level C++ program implementing basic sorting and searching algorithms.

## Sorting Algorithms

- Bubble Sort — O(n²)
- Selection Sort — O(n²)
- Merge Sort — O(n log n)
- Quick Sort — O(n log n) average, O(n²) worst case

## Searching Algorithms

- Linear Search — O(n)
- Binary Search — O(log n)

## Concepts Used

- C++ functions
- Arrays
- Loops
- Switch-case
- Recursion
- Sorting and searching algorithms

## Language

C++
